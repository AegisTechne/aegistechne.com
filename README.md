# Aegis Techne

A static, single-page marketing site for Aegis Techne, a fractional CISO and GRC practice serving New York and New Jersey. It is plain HTML and inline CSS with no build step, no libraries, and no third-party requests. The only script is `main.js`, which draws the animated ASCII shield in the hero panel (it pauses off-screen and renders a still frame under `prefers-reduced-motion`). The site is intended to be served from GitHub Pages at aegistechne.com.
